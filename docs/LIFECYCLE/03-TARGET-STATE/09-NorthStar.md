# NorthStar Case Study

# Target State

## Purpose

This case study demonstrates how the Target State stage of the Enterprise Network Architecture Framework (ENAF) is applied within a real enterprise transformation programme.

Following the successful completion of the Current State Assessment, NorthStar Retail Group has established a trusted understanding of its existing business and technology environment. The organisation now shifts its focus from understanding the present to designing the future.

The purpose of the Target State stage is to define the future enterprise architecture that will enable NorthStar to achieve its strategic business objectives while addressing the gaps, risks, and limitations identified during the Current State Assessment.

Rather than selecting individual technologies, the Target State establishes the desired business capabilities, operating model, and architectural direction that will guide all subsequent architecture and implementation activities.

---

# Business Challenge

The Strategy stage established several key transformation objectives.

NorthStar intends to become a cloud-first, digitally enabled retailer capable of supporting continued global growth while improving customer experience, operational efficiency, and business resilience.

The Current State Assessment confirmed that the existing environment presents several challenges, including:

- Ageing network infrastructure across regional offices and stores.
- Multiple legacy applications providing overlapping capabilities.
- Inconsistent security controls between locations.
- Limited cloud integration.
- Manual operational processes.
- Poor visibility across infrastructure and services.
- High operational complexity resulting from acquisitions.

Although the existing environment continues to support day-to-day operations, it cannot efficiently support NorthStar's long-term transformation strategy.

---

# Target State Vision

The Enterprise Architecture team develops a future-state vision that aligns technology investments with business strategy.

The Target State is designed around several guiding principles.

## Business

- Simplified global operating model.
- Standardised business capabilities.
- Improved customer experience.
- Faster delivery of business change.
- Greater organisational agility.

## Applications

- Reduced application complexity.
- Modern SaaS-first application portfolio.
- API-driven integration.
- Elimination of duplicate platforms.

## Data

- Enterprise-wide information architecture.
- Improved data governance.
- Trusted business reporting.
- Master data management.

## Technology

- Cloud-first infrastructure.
- Platform standardisation.
- Infrastructure automation.
- Standard technology lifecycle management.

## Security

- Zero Trust architecture.
- Identity-first security.
- Security by design.
- Consistent security governance.

## Network

- Software-defined global connectivity.
- Secure cloud connectivity.
- Internet-first branch architecture.
- Standardised network services.
- High availability across critical locations.

---

# Future Business Architecture

Business stakeholders define how NorthStar should operate over the coming years.

The future operating model introduces:

- Global business capability standards.
- Standard business processes.
- Simplified organisational structures.
- Shared enterprise services.
- Increased digital self-service capabilities.

Business capabilities become the primary driver for future technology investment decisions.

---

# Future Technology Direction

The future technology architecture focuses on standardisation and simplification.

The Enterprise Architecture team defines a strategic direction that includes:

- Cloud-first platforms.
- Standard hosting models.
- Common integration services.
- Enterprise automation capabilities.
- Modern observability platforms.
- Standard technology lifecycle management.

Technology diversity is reduced wherever practical to simplify operations and improve long-term sustainability.

---

# Future Security Architecture

Security is embedded throughout the future architecture.

The Target State introduces:

- Zero Trust principles.
- Centralised Identity and Access Management.
- Consistent security policies.
- Network segmentation.
- Security monitoring across all environments.
- Improved cyber resilience.

Security becomes an integrated architectural capability rather than a standalone technology function.

---

# Future Network Architecture

NorthStar defines a modern enterprise network capable of supporting cloud services, retail operations, distribution centres, and remote users.

The future network architecture includes:

- Software-defined WAN.
- Secure internet connectivity.
- Direct cloud connectivity.
- High-availability regional hubs.
- Secure remote access.
- Standard branch networking.
- Consistent network segmentation.

The future network is designed to support global expansion while reducing operational complexity.

---

# Architecture Principles

Throughout the Target State stage, the Enterprise Architecture team establishes architectural principles that will guide all future solution designs.

Examples include:

- Business before technology.
- Cloud first.
- Security by design.
- Automation by default.
- Standardise before customising.
- API-first integration.
- Reuse before replace.
- Design for resilience.
- Operational simplicity.

These principles ensure consistency throughout future architecture and implementation activities.

---

# Stakeholder Validation

The proposed Target State is reviewed with business and technology stakeholders.

The review confirms that the future architecture:

- Supports the approved business objectives.
- Addresses the findings of the Current State Assessment.
- Aligns with organisational priorities.
- Meets governance expectations.
- Is achievable within the organisation's transformation programme.

Minor refinements are incorporated before governance approval.

---

# Decision Gate

Following completion of the Target State activities, NorthStar submits the future-state architecture for governance review through **TS-DG-01**.

The Architecture Review Board confirms that:

- All Target State activities have been completed.
- Required deliverables have been produced.
- Business objectives are fully supported.
- Current State findings have been addressed.
- Stakeholder agreement has been achieved.
- Architectural principles have been defined.
- Compliance and governance requirements have been considered.

The Target State is formally approved.

The approved Target State outputs now become the mandatory inputs for the Architecture stage.

---

# Outcome

By completing the Target State stage, NorthStar has established a clear architectural vision for its future enterprise.

The organisation now has:

- A defined future business architecture.
- A modern application strategy.
- A future data architecture.
- A standard technology architecture.
- An integrated security architecture.
- A scalable network architecture.
- Enterprise architecture principles.
- A unified future-state architecture vision.

Most importantly, NorthStar now has an approved architectural blueprint that provides a common direction for all future architecture work.

The programme can now proceed to the Architecture stage, where the approved Target State will be translated into detailed reference architectures, solution patterns, and implementation-ready designs.
