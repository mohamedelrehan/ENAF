# Target State

## Overview

The Target State stage defines the future-state enterprise architecture required to achieve the organisation's strategic objectives and transformation vision.

Building upon the approved Strategy outputs and the validated Current State Assessment, this stage establishes how the organisation should operate in the future across business capabilities, applications, data, technology, security, and network architecture.

Rather than selecting individual products or implementation approaches, the Target State provides a technology-independent architectural vision that guides all subsequent architecture and transformation activities.

The outputs produced during this stage become the approved architectural baseline used throughout the remainder of the ENAF lifecycle.

---

# Objectives

The objectives of the Target State stage are to:

- Define the future business architecture.
- Design the future application architecture.
- Establish the future data architecture.
- Define the future technology architecture.
- Develop the future security architecture.
- Define the future network architecture.
- Establish enterprise architecture principles.
- Produce a unified future-state architecture.
- Prepare the future architecture for governance approval.

---

# Lifecycle Position

The Target State stage is the third stage of the Enterprise Network Architecture Framework (ENAF).

```text
Strategy
    │
    ▼
Current State
    │
    ▼
Target State
    │
    ▼
Architecture
```

The stage begins after the successful approval of the Current State stage through **CS-DG-01** and concludes with governance approval through **TS-DG-01**.

# Decision Gate

The stage concludes with **TS-DG-01**, which confirms that:

- All Target State activities have been completed.
- Required deliverables have been produced.
- The future architecture aligns with approved Strategy outputs.
- The future architecture addresses Current State findings.
- Stakeholders have reviewed the proposed architecture.
- Governance and compliance requirements have been satisfied.

Following approval, all Target State deliverables become approved **TS-OUT** outputs and form the official architectural baseline for the Architecture stage.

# Summary

The Target State stage transforms business strategy and current-state knowledge into a clear, approved vision of the future enterprise architecture.

By defining the desired business capabilities, technology direction, architectural principles, and future operating model, the stage establishes a common architectural blueprint that guides all subsequent architecture and implementation activities.

Following approval through **TS-DG-01**, the approved Target State outputs become the mandatory inputs for the Architecture stage, ensuring continuity, governance, and full lifecycle traceability throughout the ENAF framework.
