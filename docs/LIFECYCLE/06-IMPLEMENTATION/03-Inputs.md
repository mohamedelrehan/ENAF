# Inputs

## Purpose

The Implementation stage begins once the Enterprise Roadmap has been approved through **RM-DG-01**.

At this point, planning activities are complete, and the organisation is ready to execute the approved transformation through programmes, projects, delivery teams, and controlled releases.

The inputs to this stage provide the strategic direction, architectural guidance, governance decisions, organisational readiness, and delivery resources required to successfully implement enterprise transformation.

These inputs ensure that implementation activities remain fully traceable to the approved business strategy, Enterprise Architecture, and transformation roadmap.

---

# Input Categories

The Implementation stage receives inputs from all previous lifecycle stages.

These inputs are grouped into six categories:

- Strategic Inputs
- Architecture Inputs
- Roadmap Inputs
- Governance Inputs
- Delivery Inputs
- Organisational Inputs

# Input Flow

Implementation receives approved outputs from every preceding lifecycle stage.

```text
Strategy
      │
      ▼
Current State
      │
      ▼
Target State
      │
      ▼
Architecture
      │
      ▼
Roadmap (Approved)
      │
      ▼
Implementation
```

Only approved outputs are permitted to enter the Implementation stage.

---

# Input Validation

Before implementation begins, the following conditions should be confirmed:

- Strategic objectives are approved.
- Target State has been accepted.
- Enterprise Architecture is approved.
- Roadmap has passed RM-DG-01.
- Transformation programmes are defined.
- Projects have been established.
- Programme governance is in place.
- Funding has been approved.
- Resources have been assigned.
- Business sponsors have accepted ownership.

Failure to satisfy these conditions should prevent implementation from commencing.

---

# Summary

The Implementation stage depends upon a complete set of approved strategic, architectural, governance, roadmap, delivery, and organisational inputs.

Together, these inputs provide the direction, authority, resources, and governance required to execute enterprise transformation while maintaining alignment with business objectives and Enterprise Architecture.
