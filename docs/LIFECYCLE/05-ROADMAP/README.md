# Checklist

The Roadmap Checklist provides a structured validation process to ensure that the enterprise transformation roadmap has been fully developed, reviewed, prioritised, and is ready for governance approval.

The checklist confirms that all Roadmap activities have been completed, required deliverables have been produced, implementation priorities have been agreed, and the organisation is ready to begin the Implementation stage.

Completion of this checklist is required before submitting the Roadmap stage for **RM-DG-01**.

---

# Purpose

The purpose of this checklist is to verify that the Roadmap stage has produced a complete, realistic, and governed transformation plan that is ready for formal approval.

It helps ensure that:

- Transformation initiatives have been identified.
- Priorities have been agreed.
- Dependencies have been documented.
- Implementation waves have been defined.
- Resources and investment have been validated.
- Risks have been assessed.
- Governance requirements have been satisfied.
- The organisation is ready for implementation.

# Summary

The Roadmap Checklist provides a structured validation process to ensure that the enterprise transformation roadmap is complete, prioritised, achievable, and ready for governance approval.

By confirming initiative prioritisation, dependency management, implementation planning, resource alignment, governance, stakeholder readiness, and deliverable quality, the checklist ensures that the Roadmap stage can be confidently approved and used as the authorised transformation plan for the Implementation stage.

---

# Next Step

Once this checklist has been completed, submit the Roadmap stage for **RM-DG-01 Roadmap Decision Gate**.

Following successful approval, release the approved **RM-OUT** outputs and begin the **Implementation** stage of the ENAF lifecycle.
