# Deliverables

The Architecture stage produces the approved enterprise architecture deliverables that define how the organisation's future-state vision will be realised through governed architectural designs, standards, principles, and reusable reference architectures.

These deliverables provide the architectural foundation for all future solution designs and transformation initiatives. They ensure that projects are developed consistently, aligned with enterprise standards, and traceable back to the approved Target State.

Together, these deliverables establish the enterprise architectural baseline that will be reviewed during the Architecture Decision Gate (**AR-DG-01**) before progressing to the Roadmap stage.

---

# Purpose

The purpose of the Architecture deliverables is to provide a complete, governed, and reusable enterprise architecture that:

- Defines enterprise architecture across all domains.
- Establishes architecture principles and standards.
- Provides reusable reference architectures.
- Standardises technology decisions.
- Enables consistent solution architecture.
- Supports governance and architectural compliance.
- Provides the foundation for transformation planning.

# Deliverable Validation

Before requesting governance approval, verify that:

- All Architecture activities have been completed.
- Every required DEL-AR deliverable has been produced.
- Deliverables are internally consistent.
- The architecture aligns with the approved Target State.
- Enterprise architecture principles have been applied.
- Architecture standards have been documented.
- Reference architectures have been completed.
- Stakeholders have reviewed the enterprise architecture.
- Deliverables are ready for governance review.

---

# Governance

The Enterprise Architect is responsible for ensuring that all Architecture deliverables are complete, accurate, governed, and aligned with the approved Strategy, Current State, and Target State outputs.

Only completed deliverables should be submitted for governance review through **AR-DG-01**.

Following approval, these deliverables become the approved enterprise architecture baseline used during the Roadmap stage.
